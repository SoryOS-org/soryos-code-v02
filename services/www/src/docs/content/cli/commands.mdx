title: "Commands"

---

Every command accepts `--help` for its full flag list, for example `lutungcode run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ lutungcode run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: LutungCode review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @lutungcode/cli
      - run: lutungcode run --standalone --model anthropic/claude-sonnet-4-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ lutungcode run --model anthropic/claude-sonnet-4-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ lutungcode run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ lutungcode run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ lutungcode run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ lutungcode run --agent build "Fix the failing test"
```

View all subcommands and flags.

```bash
$ lutungcode run --help
```

## mini

Starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ lutungcode mini
```

Continue the last session.

```bash
$ lutungcode mini --continue
```

Start with a model and an initial prompt.

```bash
$ lutungcode mini --model anthropic/claude-sonnet-4-5 --prompt "Summarize this repository"
```

View all subcommands and flags.

```bash
$ lutungcode mini --help
```

## session

Manages sessions.

```bash
$ lutungcode session list
```

Limit the list and print JSON.

```bash
$ lutungcode session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ lutungcode session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ lutungcode session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ lutungcode session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ lutungcode session import session.json
```

Import into a specific directory.

```bash
$ lutungcode session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ lutungcode session --help
```

## auth

Manages AI providers and credentials.

```bash
$ lutungcode auth list
```

List them as JSON.

```bash
$ lutungcode auth list --format json
```

Log in to a provider.

```bash
$ lutungcode auth login anthropic
```

Log in with a specific authentication method.

```bash
$ lutungcode auth login anthropic --method key
```

Log out of a saved account.

```bash
$ lutungcode auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ lutungcode auth switch anthropic work
```

View all subcommands and flags.

```bash
$ lutungcode auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ lutungcode mcp list
```

Add a remote server.

```bash
$ lutungcode mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ lutungcode mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ lutungcode mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ lutungcode mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ lutungcode mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ lutungcode mcp logout sentry
```

View all subcommands and flags.

```bash
$ lutungcode mcp --help
```

## plugin

Manages plugins.

```bash
$ lutungcode plugin list
```

```bash

```


Check package plugins for updates.

```bash
$ lutungcode plugin check
```

```bash
$ lutungcode plugin update
```

Remove a plugin from global configuration.

```bash
$ lutungcode plugin remove @example/lutungcode-tui
```

View all subcommands and flags.

```bash
$ lutungcode plugin --help
```

## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ lutungcode serve
```

Bind to all interfaces on a fixed port.

```bash
$ lutungcode serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ lutungcode serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ lutungcode serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ lutungcode pair
```

Use an external URL in the links.

```bash
$ lutungcode pair --url https://dev.example.com
```

Pair from anywhere through an OpenTunnel remote address. This exposes the
server to the internet, so the first time it enables remote access it explains
this and asks you to accept. See [Remote access](/cli/web#remote-access).

```bash
$ lutungcode pair --remote
```

Accept without a prompt, for example in a script without a terminal.

```bash
$ lutungcode pair --remote --yes
```

View all subcommands and flags.

```bash
$ lutungcode pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ lutungcode service start
```

Restart it.

```bash
$ lutungcode service restart
```

Show its status.

```bash
$ lutungcode service status
```

Stop it.

```bash
$ lutungcode service stop
```

Read a setting.

```bash
$ lutungcode service get hostname
```

Set a setting.

```bash
$ lutungcode service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ lutungcode service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ lutungcode service set env LUTUNGCODE_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ lutungcode service unset hostname
```

View all subcommands and flags.

```bash
$ lutungcode service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ lutungcode reload
```

## api

Makes a request to the running server.

```bash
$ lutungcode api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ lutungcode api session.list --param limit=10
```

Send a JSON body.

```bash
$ lutungcode api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ lutungcode api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ lutungcode api --help
```

## upgrade

Upgrades LutungCode to the latest or a specific version. Alias: `update`.

```bash
$ lutungcode upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ lutungcode upgrade 2.0.21 --method bun
```

View all subcommands and flags.

```bash
$ lutungcode upgrade --help
```

## uninstall

Stops background services, removes the global cache, and uninstalls LutungCode. Session data, configuration, and
state are not removed.

```bash
$ lutungcode uninstall
```

Preview what would be removed.

```bash
$ lutungcode uninstall --dry-run
```

View all subcommands and flags.

```bash
$ lutungcode uninstall --help
```
